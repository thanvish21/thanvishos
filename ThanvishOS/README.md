# ThanvishOS

Personal AI‑operating system to help you become a better student, programmer, and open‑source contributor.

## Overview

- **Discovery Engine** – scans your filesystem for repositories, notes, PDFs, etc.
- **Planner Engine** – builds daily/weekly plans based on academic deadlines and project priorities.
- **Project Engine** – tracks active, shipped and abandoned projects.
- **Open‑Source Engine** – manages contributions and PR workflow.
- **Mastery Engine** – records skill evidence and AI‑dependency.
- **Game / Simulation Engine** – generates learning games for identified weaknesses.
- **Integration** – WhatsApp, Hermes, GitHub, and hyperresearch knowledge base.

The repository contains a runnable CLI (`thanvish.py`) and a full directory layout under `ThanvishOS/`.
